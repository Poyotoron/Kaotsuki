# 送り手の使い方

送り手 `Kaotsuki Sender` は、マップを読んでブレンドシェイプごとのスライダーを並べ、値を OSC で VRChat に送るアプリです。
画面は上から次の順に並んでいます。

| 区画 | 内容 |
|---|---|
| マップ | 開くマップの選択と、受信の状態 |
| 操作 | `Kaotsuki` / `口パク` のトグル、`リセット`、送信先と `⚙` |
| 表情 | `表情を保存…` / `AnimationClip として保存…` / `表情を読み込む…` |
| 検索 | ブレンドシェイプ名での絞り込み |
| スライダー | メッシュごと・区切りごとに折り畳まれた一覧 |

## マップを選ぶ

| 操作 | 内容 |
|---|---|
| マップのドロップダウン | `%LOCALAPPDATA%\Kaotsuki\Maps\` のマップを、新しい順に並べます |
| `↻` | 一覧を読み直します |
| `ファイルを開く…` | 別の場所にあるマップ（JSON）を開きます |

複数のアバターで共有しているマップは `マップ名（N アバター）` と表示されます。
VRChat から受信していれば、アバターを変えたときに自動で切り換わります（[マップと自動切換え](maps.md)）。

マップの下の 1 行は受信の状態です。

| 表示 | 意味 |
|---|---|
| `VRChat から受信中（ポート 9001）` | アバターの変更と ON / OFF を受け取っています |
| `受信できません（ポート 9001 を他のアプリが使っている可能性があります）` | 受信だけが使えません。送信はできます |
| `VRChat から受信しない設定です` | `⚙` で受信を切っています |

## トグルとリセット

| 操作 | 内容 |
|---|---|
| `Kaotsuki` トグル | 受け手の ON / OFF です（起動時は ON）。OFF の間はアバターが普段の表情に戻り、**スライダーの位置は残ります**。ON に戻すと作りかけの表情に戻ります |
| `口パク` トグル | Kaotsuki が ON の間も口パクを動かすかを切り替えます（起動時は OFF） |
| `リセット` | スライダーとアバターの表情を既定値に戻します。ON / OFF の状態は変わりません |

!!! tip "普段の表情と見比べる"
    `Kaotsuki` を OFF にするとジェスチャーなどの普段の表情に戻り、ON にすると作りかけの表情に戻ります。
    スライダーを動かさずに何度でも見比べられます。

Expression Menu の `Kaotsuki` にある `ON` / `口パク` を切り替えると、送り手のトグルにも反映されます（受信しているとき）。

## スライダー

| 操作 | 内容 |
|---|---|
| スライダー | ウェイト（0〜100）を変えます |
| 右の数値欄 | 0〜100 の数値を入力し、`Enter` かほかの場所をクリックで反映します。`Esc` で取り消します |
| `↺` | そのブレンドシェイプを既定値に戻します |
| 検索欄 | 名前の一部で絞り込みます。一致したものを含むグループが開き、検索を消すと元の開閉に戻ります |

- 数値欄は全角の数字も受け付けます。範囲外や数字以外は元に戻り、`0〜100 の数値を入力してください` と表示されます。
- 値は約 0.4 刻みです。たとえば `50` と入力すると `50.2` になります。
- 一覧は 1 行おきに色分けされ、マウスを乗せた行が強調されます。

!!! note "スライダーを素早く動かしたとき"
    送り手は、ブレンドシェイプを 1 本ずつ順に送ります（他のプレイヤーにも同じ表情が届くようにするため）。
    たくさんのスライダーを一度に動かすと、すべてが反映されるまで少し時間がかかります。

## 設定（`⚙`）

| 項目 | 既定 | 内容 |
|---|---|---|
| 送信先ホスト | `127.0.0.1` | VRChat が動いている PC。同じ PC なら変えません |
| ポート | `9000` | VRChat の OSC 受信ポート |
| 保持時間（ミリ秒） | `250` | 別のブレンドシェイプへ切り替えるまでの待ち時間（100〜1000） |
| VRChat から受信する | ON | アバターの変更と ON / OFF を受け取ります |
| 受信ポート | `9001` | VRChat の OSC 出力を受け取るポート |

!!! tip "他のプレイヤーから見て表情が揃わないとき"
    保持時間を長くすると、他のプレイヤーへの反映が確実になります（そのぶん、全体の反映は遅くなります）。

設定は `%APPDATA%\net.maaaaa.kaotsuki.sender\settings.json` に保存されます。
