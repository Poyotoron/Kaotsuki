# マップと自動切換え

**マップ**は、受け手と送り手をつなぐ「番号 ↔ ブレンドシェイプ」の対応表です。
受け手がビルドのたびに書き出し、送り手がそれを読んでスライダーを並べます。

## マップの保存先と書き出し

マップは `%LOCALAPPDATA%\Kaotsuki\Maps\<マップ名>.json` に保存されます。
受け手の Inspector の `マップのフォルダを開く`、または Unity のメニュー `Tools > Kaotsuki > Open Map Folder` で開けます。

| 書き出されるとき |
|---|
| Play Mode に入ったとき |
| アバターをアップロードしたとき |
| Inspector の `マップを書き出す` / `送り手を起動` を押したとき |

!!! warning "マップと VRChat 上のアバターはずれることがあります"
    設定を変えて Play Mode に入るとマップは新しくなりますが、VRChat 上のアバターはアップロードし直すまで古いままです。
    設定を変えたら、アップロードし直してください。

## 衣装違いのアバターでマップを共有する

同じ素体で衣装だけ違うアバターが何体もあると、マップも衣装の数だけ増えてしまいます。
**同じマップ名のアバターは 1 つのマップを共有する**ので、送り手のマップを 1 つにまとめられます。

### 素体の Prefab に組み込む（おすすめ）

1. 素体の Prefab を Prefab モードで開きます。
2. アバターを右クリックし、`Kaotsuki` → `Setup` を選びます。
3. Prefab を保存します。

`マップ名` には素体の名前が入り、それを元にした衣装違いの Prefab Variant すべてに引き継がれます。
何もしなくても、すべての衣装が同じマップを使います。

### 後から揃える

それぞれのアバターの `Kaotsuki` の Inspector で、`マップ名` を同じ文字列にしてください。

!!! warning "登録したブレンドシェイプの構成が同じである必要があります"
    共有できるのは、登録したブレンドシェイプの並び（メッシュ・名前・順番）が同じアバターどうしです。
    構成が違うアバターで書き出すと、他のアバターの登録が外れ、
    `共通マップの構成が変わりました` という警告が出ます。外れたアバターは、そのアバターでビルドし直すと再び登録されます。

    既定値（ウェイトの初期値）だけの違いは問題ありません。

## アバターを変えたときの自動切換え

送り手が VRChat から受信していれば（[送り手の使い方](sender.md)）、VRChat でアバターを変えたときに、
**そのアバターのマップに自動で切り換わり、約 1.5 秒後に Kaotsuki を ON にします。**

| 状況 | 送り手の動き |
|---|---|
| 変えた先のアバターのマップがある | そのマップに切り換えます（共有しているマップも含みます） |
| 同じマップのまま | スライダーを既定値に戻します |
| マップが見つからない | `このアバターのマップが見つかりません` と表示し、今のマップのままにします |

!!! note "初めてアップロードしたアバター"
    自動切換えは、アップロード済みのアバターの ID で行います。初めてアップロードしたアバターは、
    アップロード後に一度 Play Mode に入るか、`マップを書き出す` を押してください。ID 入りのマップになります。
