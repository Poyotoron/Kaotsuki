# クイックスタート

アバターに受け手を組み込み、VRChat の中で表情を動かすまでの最短の手順です。

## 1. 受け手を追加する

1. Hierarchy でアバター（`VRC Avatar Descriptor` が付いたオブジェクト、またはその子）を右クリックします。
2. `Kaotsuki` → `Setup` を選びます。

アバターの直下に `Kaotsuki` というオブジェクトができ、`Body` メッシュが登録された状態になります。
Expression Menu には `Kaotsuki` サブメニュー（`ON` / `口パク`）が追加されます。

!!! tip "やり直したいとき"
    Setup は `Ctrl + Z` 1 回で取り消せます。同じアバターで 2 回 Setup しても、2 つ目は作られません。

## 2. 動かすブレンドシェイプを選ぶ

`Kaotsuki` オブジェクトを選び、Inspector で動かすブレンドシェイプを確認します。
既定では、登録したメッシュの**すべてのブレンドシェイプが ON** になっています。

!!! warning "表情以外のブレンドシェイプは OFF にしてください"
    Kaotsuki を ON にしている間は、登録したブレンドシェイプが**すべて** Kaotsuki の値で上書きされます。
    体型の調整や衣装用の縮小など、表情以外で触られたくないものは OFF にしてください。
    詳しくは [受け手の設定](receiver.md) を参照してください。

## 3. アップロードする

いつもどおりアバターをアップロードします。

## 4. VRChat で OSC を有効にする

VRChat の Action Menu → **Options → OSC → `Enabled`** を ON にします。

## 5. 送り手を起動する

Unity で `Kaotsuki` の Inspector を開き、`送り手を起動` を押します。
そのアバターのマップを開いた状態で送り手が起動します。

## 6. 表情を動かす

VRChat でアップロードしたアバターに着替え、送り手のスライダーを動かします。
送り手は起動時から Kaotsuki を ON にするので、スライダーに合わせてアバターの表情が変わります。

| やりたいこと | 操作 |
|---|---|
| 普段の表情に戻して見比べる | 送り手の `Kaotsuki` トグルを OFF（スライダーの位置は残ります） |
| 作りかけの表情に戻る | `Kaotsuki` トグルを ON |
| すべて既定値に戻す | `リセット` |
| 表情を保存する | `表情を保存…` または `AnimationClip として保存…` |

各操作の詳細は [送り手の使い方](sender.md) を参照してください。

!!! note "設定を変えたらアップロードし直してください"
    動かすブレンドシェイプを変えると、マップは Unity でビルドするたびに更新されますが、
    VRChat 上のアバターはアップロードし直すまで古いままです。
