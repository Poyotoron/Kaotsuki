# 口パクとまばたき

VRChat は、口パク（Viseme）と自動のまばたきのためにブレンドシェイプを動かしています。
Kaotsuki は、これらと表情の操作が両立するように動きます。

## Kaotsuki の ON / OFF による違い

| 状態 | 表情 | 口パク | まばたき・視線 |
|---|---|---|---|
| OFF | 普段どおり（ジェスチャーなど） | 普段どおり動く | 普段どおり動く |
| ON・口パク OFF | 送り手の値 | 止まる（口の形も送り手で決められる） | 止まる※ |
| ON・口パク ON | 送り手の値 | 送り手の表情のまま口パクする | 止まる※ |

※ 受け手の `ON の間まばたき・視線を止める` を OFF にすると、ON の間もまばたき・視線は動きます。

ON にしている間は、登録したブレンドシェイプを Kaotsuki だけが動かします。
ジェスチャーなど、他の仕組みで表情を変えても反映されません。

## 口パクを切り替える

ON の間に口パクを動かすかは、次のどちらかで切り替えます（既定は OFF）。

- Expression Menu の `Kaotsuki` → `口パク`
- 送り手の `口パク` トグル

どちらで切り替えても、もう一方に反映されます（送り手が受信しているとき）。
アバターを読み込み直すと、口パクは OFF に戻ります。

## 口パク・まばたきのブレンドシェイプも登録できます

`vrc.v_aa` などの口パク用や、まばたき用のブレンドシェイプも、他と同じように登録して動かせます。
受け手の一覧では `（口パク）` / `（まばたき）` と表示されます。

Kaotsuki はビルド時にこれらのブレンドシェイプの**複製**を作り、複製のほうを動かします。
元のブレンドシェイプは VRChat が動かし続けるので、OFF の間は普段どおり口パク・まばたきします。
ON・口パク ON のときは、Kaotsuki で作った口の形に口パクが重なります。

!!! note "表情ファイルや AnimationClip には元の名前で入ります"
    複製はビルドの中だけで使う名前です。保存する表情ファイル・AnimationClip には、`vrc.v_aa` などの元の名前で記録されます。
