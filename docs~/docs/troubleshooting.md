# 困ったときは

## スライダーを動かしてもアバターが変わらない

上から順に確認してください。

| 確認すること | 対処 |
|---|---|
| VRChat で OSC が有効か | Action Menu → Options → OSC → `Enabled` を ON にします |
| 送り手の `Kaotsuki` トグルが ON か | ON にします |
| 開いているマップが、今のアバターのものか | 送り手のマップを選び直します |
| 設定を変えた後にアップロードし直したか | アップロードし直します |
| アバターを上書きアップロードした直後か | 下の「上書きアップロードした後に OSC が効かない」を参照してください |
| 送信先のホスト・ポートが正しいか | `⚙` で `127.0.0.1` / `9000` になっているか確かめます |

## 上書きアップロードした後に OSC が効かない

VRChat は、アバターごとの OSC の設定ファイルを保存しています。パラメータを追加したアバターを上書きアップロードすると、
古い設定のまま OSC を受け付けないことがあります。

Action Menu → **Options → OSC → `Reset Config`** を実行してください。

## 一部のブレンドシェイプだけ動かない

| 原因 | 対処 |
|---|---|
| 受け手の一覧で OFF になっている | ON にしてアップロードし直します |
| 区切りとして扱われている | `区切りを編集` で区切りから外し、アップロードし直します |
| `（固定）` と表示されている | AAO Avatar Optimizer で固定されるため動かせません（[他のツールとの併用](other-tools.md)） |

## ON にすると体型や衣装の形が変わる

ON の間は、登録したブレンドシェイプが**すべて** Kaotsuki の値で上書きされます。
体型の調整や衣装用の縮小など、表情以外のブレンドシェイプは受け手の一覧で OFF にしてください。

ビルド時に値を変えるツールを使っている場合は、[他のツールとの併用](other-tools.md) も参照してください。

## 他のプレイヤーから見ると表情が違う

送り手はブレンドシェイプを 1 本ずつ順に送ります。たくさん動かした直後は、すべてが届くまで時間がかかります。
しばらく待っても揃わない場合は、送り手の `⚙` で保持時間を長くしてください。

## アバターを変えてもマップが切り換わらない

| 確認すること | 対処 |
|---|---|
| 受信の状態が `VRChat から受信中` か | `受信できません…` なら、下の「受信できません と表示される」を参照してください |
| そのアバターを初めてアップロードしたか | アップロード後に一度 Play Mode に入るか、`マップを書き出す` を押します |
| `このアバターのマップが見つかりません` と表示される | そのアバターの受け手でマップを書き出します |

## 「受信できません」と表示される

送り手は VRChat からの OSC を `127.0.0.1:9001` で受け取ります。他の OSC アプリが 9001 番を使っていると受け取れません。
送信はそのまま使えます。

- 他の OSC アプリを閉じてから、送り手の `⚙` で `保存` を押すと受信をやり直します。
- 受信ポートを変える場合は、VRChat 側の OSC の出力先も合わせて変える必要があります。

## AnimationClip を読み込めない

| 表示 | 原因と対処 |
|---|---|
| `テキスト形式で保存された AnimationClip だけを読み込めます` | Unity の Asset Serialization が `Force Text` 以外で保存されたクリップです |
| `対応していないファイルです` | AnimationClip ではないファイルです |
| `… 件はこのアバターにありません` | クリップのブレンドシェイプ名が、今のアバターに無いものです |

## 保存した AnimationClip が Unity に出てこない

Unity のプロジェクトの `Assets/` の中に保存したか確かめてください。保存した後、Unity に切り替えると取り込まれます。

## 「共通マップの構成が変わりました」と警告が出る

同じマップ名で、登録したブレンドシェイプの構成が違うアバターを書き出しました。
衣装違いで共有するつもりなら、それぞれのアバターで登録を揃えてください。
別のマップにしたいなら、`マップ名` を変えてください。詳しくは [マップと自動切換え](maps.md) を参照してください。
