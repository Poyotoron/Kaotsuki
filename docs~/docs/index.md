# はじめに

**Kaotsuki** は、VRChat の外からアバターの表情（ブレンドシェイプ）を **OSC で 1 本ずつ直接動かせる**ツールです。

表情を作り込むとき、Unity で値を変えてはアップロードし直し、VRChat で見た目を確かめる……という往復が発生しがちです。
Kaotsuki を組み込んでおけば、**VRChat の中で見た目を確かめながら**、スライダーでブレンドシェイプの値を調整できます。
できあがった表情は、そのまま Unity の AnimationClip として保存できます。

## 2 つの部品でできています

| 部品 | 置き場所 | 役割 |
|---|---|---|
| **受け手** | アバター（Unity パッケージ） | OSC で受け取った値で、アバターのブレンドシェイプを動かします |
| **送り手** | Windows アプリ `Kaotsuki Sender` | ブレンドシェイプごとのスライダーを並べ、値を OSC で VRChat に送ります |

受け手と送り手は、**マップ**（どの番号がどのブレンドシェイプかの対応表）でつながっています。
マップは Unity でビルドするたびに自動で書き出され、送り手はそれを読んでスライダーを並べます。

## 元のアバターを書き換えません

!!! success "組み込みはビルド時だけ"
    Kaotsuki が追加するのは、設定を持つだけのコンポーネント 1 つと、Expression Menu の項目だけです。
    FX のレイヤーとパラメータは、Play Mode に入るときやアップロードするときに自動で組み込まれます。
    コンポーネントはアップロードの成果物には残りません。

## できること・できないこと

| できること | できないこと |
|---|---|
| 登録したブレンドシェイプを 0〜100 の値で 1 本ずつ動かす | ブレンドシェイプ以外（マテリアル・ボーンなど）の操作 |
| 作った表情をファイルや AnimationClip に保存し、あとで読み込む | VRChat から今のブレンドシェイプの値を読み戻すこと |
| 既存の AnimationClip を読み込んでアバターに反映する | AnimationClip の時間変化の再生（読み込むのは最初の値だけ） |
| VRChat でアバターを変えると、送り手のマップを自動で切り換える | Windows 以外での送り手の起動 |
