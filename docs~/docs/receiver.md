# 受け手の設定

Setup で作った `Kaotsuki` オブジェクトの Inspector で、動かすブレンドシェイプやマップ名を設定します。
Inspector は上から次の順に並んでいます。

| 区画 | 内容 |
|---|---|
| 状態表示 | 登録数と、使う同期パラメータの量 |
| マップ | マップ名 |
| オプション | ON の間のまばたき・視線 |
| メッシュ | 登録したメッシュと、ブレンドシェイプごとの ON / OFF |
| 操作ボタン | マップの書き出し・送り手の起動など |

## 状態表示

一番上に `登録数: N（枠 C・同期 B bit）` と表示されます。

| 表示 | 意味 |
|---|---|
| 登録数 | ON にしているブレンドシェイプの数（区切り・固定されるものは数えません） |
| 枠 | 同期パラメータの組の数。255 本ごとに 1 つ増えます |
| 同期 | Kaotsuki が使う同期パラメータの量。255 本までは 18 bit で、枠が 1 つ増えるごとに 16 bit 増えます |

!!! warning "同期パラメータは他のギミックと共有です"
    VRChat の同期パラメータの上限（256 bit）は、アバターの他のギミックと合わせて数えられます。
    登録数が 255 を超えると Kaotsuki だけで 34 bit 以上使うので、表情に使わないブレンドシェイプは OFF にして減らしてください。
    登録できるのは最大 3825 本です。

## マップ

`マップ名` は、送り手で使うマップのファイル名です。Setup したときにアバター名が入ります。
**同じマップ名のアバターは、送り手で 1 つのマップを共有します。** 空欄にするとアバター名を使います。

衣装違いのアバターで使い回す方法は [マップと自動切換え](maps.md) を参照してください。

## オプション

| 項目 | 既定 | 内容 |
|---|---|---|
| `ON の間まばたき・視線を止める` | ON | Kaotsuki を ON にしている間、VRChat の自動のまばたきと視線の動きを止めます |

口パクは、Expression Menu と送り手の `口パク` トグルで切り替えます。詳しくは [口パクとまばたき](tracking.md) を参照してください。

## メッシュ

登録したメッシュごとに、折り畳めるブロックが並びます。Setup では `Body` メッシュが自動で登録されます。

| 操作 | 方法 |
|---|---|
| メッシュを追加する | 一番下の `メッシュを追加` 欄に SkinnedMeshRenderer をドラッグ＆ドロップ |
| メッシュを外す | ブロックの見出しの `×` |
| 1 本ずつ ON / OFF | ブレンドシェイプ名の左のチェック |
| まとめて ON / OFF | `すべて ON` / `すべて OFF`（そのメッシュの全ブレンドシェイプに効きます） |
| 名前で絞り込む | `検索` 欄（大文字・小文字を区別しない部分一致） |

!!! note "検索中でも `すべて ON` / `すべて OFF` は全体に効きます"
    絞り込みは表示だけです。見えていない分まで含めて切り替わるので、注意してください。

ブロックの見出しの `登録数 a / b` は、そのメッシュで ON にしている数（a）と、操作できるブレンドシェイプの数（b）です。

### 区切りと折り畳み

アバターのブレンドシェイプは、`---目---` や `===口===` のような**中身の無いダミーのブレンドシェイプ**でカテゴリ分けされていることがよくあります。
Kaotsuki はこれを「区切り」として扱い、次の区切りまでをまとめて折り畳みます。

区切りは次のどちらかに当てはまるものを自動で判定します。

| 判定 | 例 |
|---|---|
| 名前の先頭か末尾に `-` `=` `－` `＝` `─` `━` `―` が 2 つ以上続く | `---目---`、`==Mouth==`、`Eye--` |
| 名前の先頭か末尾が記号で、**中身が空**（形が変わらない） | `【目】`、`★口★`、`#Eye` |

- 区切りは操作の対象になりません（中身が無いため）。チェックとしても表示されません。
- グループは既定で閉じています。見出しの `ON` / `OFF` で、そのグループだけをまとめて切り替えられます。
- 検索中は、グループに分けずに一致したものだけを並べます。

**自動で判定できない・誤って判定された区切り**は、`区切りを編集` で直せます。
`区切りを編集` を押すと、全ブレンドシェイプのチェックが「区切りにするか」の切り替えになります。
自動で判定されたものには `（自動）` と表示されます。

!!! warning "区切りを変えるとアップロードし直しが必要です"
    区切りはスロット（送り手と受け手の対応番号）に入らないため、区切りを変えると番号が変わります。
    区切りを編集した後や、Kaotsuki を更新して新しく区切りが判定された後は、アバターをアップロードし直してください。

### 一覧に付く印

| 印 | 意味 |
|---|---|
| `（口パク）` | VRChat の口パク（Viseme）に使われているブレンドシェイプ |
| `（まばたき）` | VRChat の自動のまばたきに使われているブレンドシェイプ |
| `（固定）` | AAO Avatar Optimizer の Freeze BlendShapes で固定されるブレンドシェイプ。操作できません |

`（口パク）` / `（まばたき）` のものも普通に登録できます。仕組みは [口パクとまばたき](tracking.md)、
`（固定）` については [他のツールとの併用](other-tools.md) を参照してください。

## 操作ボタン

| ボタン | 内容 |
|---|---|
| `マップを書き出す` | 今の設定からマップを書き出します（Play Mode に入ったときとアップロード時にも自動で書き出されます） |
| `送り手を起動` | マップを書き出してから、そのマップを開いた状態で送り手を起動します |
| `マップのフォルダを開く` | マップの保存先（`%LOCALAPPDATA%\Kaotsuki\Maps\`）をエクスプローラーで開きます |
| `表情ファイルから AnimationClip を作る…` | 送り手で保存した表情ファイルから、このアバター用の AnimationClip を作ります（[表情と AnimationClip](expressions.md)） |

## メニューに口パクがないとき

以前のバージョンで Setup した `Kaotsuki` は、Expression Menu が `ON` だけのトグルになっています。
この場合、状態表示の下に `Expression Menu に口パクの切り替えがありません。` と表示されるので、
`メニューに口パクを追加` を押してください。`Kaotsuki` サブメニュー（`ON` / `口パク`）に変わります（`Ctrl + Z` で戻せます）。

## メニューの置き場所を変える

`Kaotsuki` オブジェクトには Modular Avatar の Menu Installer と Menu Item が付いています。
Modular Avatar の通常の手順で、メニューの置き場所を変えられます。
メニューを消しても受け手は動きます（送り手から ON / OFF できます）。
